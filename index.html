``` **How the new sync works:** 1. Import your `.srt` or `.vtt`. 2. Find a line where you can clearly hear the person start speaking. 3. Pause the video **right when that line starts**. 4. Open **CC → Sync to Current Video Time**. 5. It finds the nearest subtitle cue and applies the offset. 6. If the closest subtitle is more than **8 seconds away**, it refuses to sync instead of making a random guess. A truly automatic **speech-to-subtitle synchronization** would require analyzing/transcribing the video's audio, which can't reliably be done by normal browser JavaScript alone. The new method is therefore much safer than the old random guesser.
